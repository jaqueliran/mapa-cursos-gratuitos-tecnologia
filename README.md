# Mapa de Cursos Gratuitos de Tecnologia

Curadoria independente de cursos, trilhas, formações e recursos de prática em tecnologia, organizada por estudantes da Univesp (turma 2025).

> **Transparência.** Este projeto é uma curadoria independente. Cursos, preços, certificados, requisitos e disponibilidade podem mudar. Sempre confira as condições na página oficial da instituição.

**Última revisão da curadoria:** 23 de agosto de 2026.

## Como usar este mapa

1. Escolha uma direção, não uma lista inteira de cursos.
2. Confira a coluna **Gratuidade** antes de se inscrever: acesso ao conteúdo, certificado e exame podem ter regras diferentes.
3. Combine estudo com prática e registre projetos no GitHub ou em um portfólio.

### Legenda de credenciais

- **Certificado de conclusão:** comprova participação/conclusão na plataforma; não equivale, por si só, a certificação profissional.
- **Certificação:** credencial obtida por exame, avaliação ou processo definido pela instituição.
- **Trilha/formação:** sequência de conteúdos; pode ou não emitir credencial.
- **Acesso gratuito; certificado pago:** o conteúdo pode ser estudado sem custo, mas a credencial verificada é cobrada.
- **Programa seletivo:** requer inscrição, critérios e/ou vagas; não é um curso permanentemente aberto.

## Profissionais da educação em transição para tecnologia

Profissionais da educação costumam trazer comunicação, pensamento crítico, planejamento, pesquisa, avaliação, facilitação, organização e design de aprendizagem. Essas competências ajudam na transição, mas **não substituem** a formação técnica, a prática e um portfólio.

Uma sugestão de percurso — adaptável, não obrigatório:

Educação → letramento digital → fundamentos de tecnologia → lógica e programação → Python → dados e SQL → estatística → IA → projetos → portfólio → oportunidades profissionais.

Projetos que conectam as duas áreas podem ser bons pontos de partida: análise de dados educacionais públicos, automação de rotinas, material didático interativo, dashboard de aprendizagem ou protótipo de IA com avaliação crítica de limites e vieses.

## Prática, projetos e portfólio

Curso → prática → projeto → GitHub → portfólio.

Ideias de projeto: análise de dados públicos, automação em Python, dashboard, API simples, aplicação web, experimento pequeno de IA, protótipo RAG com fontes citadas ou projeto educacional. Inclua no repositório um README do projeto: problema, dados/fontes, decisões, limites e como executar.

## Como escolher uma trilha

| Interesse atual | Comece por |
|---|---|
| Estou começando | Fundamentos + lógica + Python |
| Gosto de números e investigação | Dados + SQL + estatística + Python |
| Quero construir aplicações | Programação + web + APIs + banco de dados |
| Gosto de infraestrutura | Linux + redes + cloud + DevOps |
| Quero estudar IA | Python + dados + ML + IA generativa |
| Venho da educação | Fundamentos + Python + dados/IA + projeto ligado à educação |

### Trilha sugerida — Dados e análise de dados

| Etapa | Foco | Prática sugerida |
|---|---|---|
| 1. Organizar e explorar | Excel ou Google Sheets | Limpar uma planilha e responder uma pergunta simples. |
| 2. Consultar dados | SQL e bancos de dados | Consultar, filtrar e combinar tabelas pequenas. |
| 3. Programar | Python | Automatizar uma análise ou transformação de dados. |
| 4. Analisar | NumPy, Pandas e estatística descritiva | Investigar padrões, valores ausentes e possíveis vieses. |
| 5. Comunicar | Visualização e dashboard | Criar gráficos que respondam à pergunta inicial. |
| 6. Mostrar o processo | Projeto com dados públicos | Documentar fonte dos dados, decisões, limites e resultados. |

Esta é uma orientação, não uma sequência obrigatória. Em cada etapa, tente responder a uma pergunta real com dados antes de avançar.
